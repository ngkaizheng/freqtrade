## 0. 为什么冻结

不是因为"没找到策略"，而是因为**已经得到了一套比"找到一个神奇指标"更有价值的东西**：

1. MA200 的作用是 **exposure / risk management**，不是预测 crash
2. 慢确认信号确实减少 whipsaw，但**牺牲快速风险保护**
3. 两层 MA 信号高度同步时，layering **只是制造 delay**
4. 波动率/信用/广度信号在 MA200 已触发后，**未证明能预测进一步下跌**
5. **最重要**：randomized placebo 证明「减仓本身机械地降低 Max DD」，
   不能把 DD 改善直接归因于 signal
6. 已建立 regression tests、data integrity checks、engine cross-check、
   walk-forward、holdout、permutation test

**研究目标是「不断排除错误的 market-timing assumptions」，这本身已很有价值。**

## 2. 各阶段决策与证据

### 阶段 0：早期探索（H1 之前）

这些是**未预注册**的探索性实验。结论仅供参考，**不作为生产依据**。

| 实验 | 结论 |
|---|---|
| `backtest_adi_analysis.py` | ADI MA20/MA50 交叉：**-18.64%** vs 买入持有 +723.54%。发现 NaN 幽灵信号（5.45pp 差异） |
| `run_comparison.py` | 9 个横截面策略；**等权持有同池 Sharpe 1.34 最高**（无需任何信号）→ 提示幸存者偏差 |
| `run_vs_equalweight.py` | **关键**：换成等权同池基准后，**8 个策略中 0 个显著跑赢** |
| `run_robustness.py` | 100 组参数网格 + walk-forward + Deflated Sharpe |
| `run_factor_forms.py` | 多空动量 Sharpe 1.24 < 等权多头 1.34；做空成本致命 |
| `run_winrate_analysis.py` | **胜率最高的低波动（62.2%）收益最低（11.96%）** |
| `check_survivorship.py` | yfinance **无法**提供 point-in-time 退市数据（40 只仅 8 只有数据且多为脏数据） |
| `run_market_timing.py` | 指标平均一致率 **77.1%**（验证"看太多指标没用"）；大盘择时降回撤但损收益 |
| `run_partial_timing.py` | **减半仓 (100/50) Sharpe 0.81 > 一直持有 0.77**，Sortino 0.94 vs 0.83 |
| `run_exposure_scan.py` | 四资产 × 11 档：大盘有"平台"，小盘无（IWM 仅 1/10 档有效） |
| `run_wf_fixed.py` | ⚠️ **修正了自己的 walk-forward 缺陷**（窗口内重算 MA200 造成系统性惩罚） |

**阶段 0 的关键教训**：
- 与 SPY 比较是**假的测试**（池子偏差）→ 必须用等权同池
- 胜率是**过程指标**，期望值才是目标函数
- 指标高度重复，叠加只会增加滞后

### 阶段 1：H1 — 慢确认能否减少 whipsaw？

**预注册**：`hypotheses/H1-preregistration.md`
**判定**：**部分支持**

| 维度 | 结果 |
|---|---|
| 减少 whipsaw（主要终点） | ✅ **12/12 组合换手降 75.0%-88.2%**，事件数降 80-87% |
| 保持回撤保护（非劣性） | ❌ Validation 层仅 1/4，SPY +6.44pp、IWM +11.19pp 恶化 |

**关键发现**：
- 在 `Close<MA200` 的所有交易日中，**75-78%** 的时候 `MA50` 也已跌破 →
  两信号**几乎同一个信号**
- 假警报率需做**基线校正**（原始 80-95% 是牛市基线效应，不是信号质量）

**决策**：❌ 不纳入生产。慢确认的代价（离场更晚）超过了它的好处。

---

### 阶段 2：H2 — 分层暴露能否同时拿到快保护与低摩擦？

**预注册**：`hypotheses/H2-preregistration.md`
**判定**：**不支持**

| 层 | 机制假设达成 |
|---|---|
| Research | **0/4** |
| Validation | **0/4** |
| Holdout（仅报告） | 1/4 |

**失败的机制性原因**（比结果本身更重要）：
- **75% 中间态平均只占总时间 6.4%**，中位持续仅 3-4 天
- H2 与臂 B 的暴露**只在 6.4% 的交易日不同**
- H2 退化为「臂 B 加一点延迟」

**决策**：❌ 不纳入生产。
**并且**：不调整 75/50 分层（那是参数搜索），记录失败。

---

### 阶段 3：H3 — 不同信息维度能否提供增量信息？

**预注册**：`hypotheses/H3-preregistration.md`
**判定**：**不支持** —— 但失败原因与预期不同

| 类别 | 方向正确 | 超出安慰剂 |
|---|---:|---:|
| H3-A 波动率（VIX 百分位） | 0/4 | 0/4 |
| H3-B 信用（HYG/LQD） | 1/4 | 0/4 |
| H3-C 广度（% above MA200） | 0/4 | 1/4 |

**最有价值的发现：方向是反的**

信号触发后，未来 63 日收益**更高**（除 IWM/H3-B 的 -0.57pp 外全为正，最高 +8.72pp）。

> 这些信号标记的是 **「超跌反弹区」**，而不是 **「进一步下跌区」**。

**方法论突破**：
- 预注册 §1 明确：**「低相关」不是进入条件；「在已有 MA200 信息条件下提供增量信息」才是**
- 若按「相关性高就排除」的做法，这三个信号都会被误判为"太像 MA200、无价值"
- **条件子样本检验 + 置换检验**才揭示出"信息方向相反"这一事实

**关键警示**：
> **「降低回撤」本身不证明信号有价值。**
> 200 次置换检验显示 **随机减仓也能得到类似改善**（36 个组合仅 2 个超出 95% 分位）。

**决策**：❌ 不纳入生产。
**并且**：不调整阈值（三分位/负号/40%），不更换代表变量。

## 4. 方法论遗产（永久保留）

### 4.1 Permutation / Placebo 检验（最重要）

> 任何「某信号改善了风险指标」的声称，**必须**先通过置换检验，
> 证明它**超出**「随机暴露变化」的分布。

**因为**：降低暴露本身就会机械地降低回撤。

**实现**：`code/run_h3.py` 的 `N_PERM=200`，随机循环位移（保持触发频率与游程结构）。

### 4.2 回归测试套件

`methodology/test_regressions.py` — **12/12 通过**

固化了 6 类"跑得通但结论会错"的 bug：

| # | Bug | 量级 |
|---|---|---|
| 1 | NaN 幽灵信号：`(ma_f>ma_s).astype(int)` 把 NaN 比较当 0 | ADI 上 5.45pp 差异 |
| 2 | `~` 在 object dtype 上返回 -1/-2（真值） | SPY 上 1874 vs 107 |
| 3 | `np.bool_` 经 `default=str` 变字符串（'False' 为真） | H2 判定 0/4 被误读为 4/4 |
| 4 | 未来函数：截断数据后前段必须完全不变 | 0.00e+00 |
| 5 | off-by-one：不得在决策当日成交 | — |
| 6 | 隐性杠杆：超配输入必须被归一化 | — |

**⚠️ 精确性修正**：`default=str` 对 Python `bool` **不触发**（原生可序列化）；
只有 `np.bool_` 才会被转成 `'False'`。

### 4.3 数据完整性门槛

FRED 的 `BAMLH0A0HYM2` 抓取曾返回 **796 行（2023 起）的不完整数据**，
表头还是 `observation_date`。若不校验会被当作有效数据**静默污染 H3**。

**已加入**：门槛校验（≥3000 行且起始 ≤2005）+ **失败即删除磁盘文件**。

### 4.4 引擎对拍（cross-check）

为跑 200 次置换，写了快速权益曲线 `fast_eq`。
**运行时对拍失败：偏差 1.18e-03** —— 因为它漏了引擎的**权重漂移**
（`w = w*g/gross`）。修复后逐点一致（<1e-9）。

> **教训**：一个"更快但语义不同"的函数会静默污染全部结果。
> 任何快速路径**必须**与参考实现逐点对拍。

### 4.5 预注册纪律

- 每个假设**先冻结**规则、阈值、数据切分、判定标准，**再跑**
- Holdout 只在规则冻结后跑一次，仅用于报告
- 失败即记录失败，**不回头调参**
- 主动披露既往污染（H1 预注册 §0 记录了 trigger_variants 已看过全样本）

## 6. 后续（FreqTrader 轨道）

**研究轨道在此冻结。** 转而回答研究无法回答的问题：

- MA200 信号实际执行的滑点？
- 信号发生在盘中还是收盘？次日开盘执行损失多少？
- ETF gap 对暴露调整的影响？
- API failure / broker downtime？
- 部分仓位调整的 rounding issue？
- 实时数据与历史回测的信号是否一致？
- 重复信号会不会重复下单？
- bot 重启后状态是否正确恢复？

**H4（可选，独立，最后一次）**：

> 在 `Close < MA200` 条件下，H3 signal 识别的状态是否提供 incremental information，
> 使**增加** exposure 相比 **matched random exposure** 能产生可重复的 forward-return improvement？

⚠️ 不要把"方向相反"直接写成 `signal = BUY`。目前只证明"值得研究"，未证明"可交易"。

**Stop Rule**：H4 是最后一个 hypothesis。若失败 → 暂停寻找 signal，
转向执行、成本、forward validation、风险控制。
