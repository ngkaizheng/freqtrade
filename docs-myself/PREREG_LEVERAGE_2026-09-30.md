# 预注册 L-1：已交付的 4h 永续空头账本能不能加杠杆？——先看几何，再看 P&L

日期：2026-09-30 · 状态：**在任何结果被计算之前冻结** · 类型：部署/风险决策研究，**不是**信号参数搜索

---

## 0. 一句话

**2026-09-27 用户问过「短周期加杠杆能不能快速涨钱」，本项目的答案是「不能，杠杆放大的是亏损」。
但那个答案是在 `PerpTrendBreakout`（5m）上测出来的，而那个策略的毛收益约等于 0、
亏损的 99.2% 是手续费——它本来就没有 edge，杠杆当然只是放大亏损。**

**已交付的 4h 空头账本不是那个策略。** F-1 测出它每笔毛赚 0.0397R、成本 0.0040R，
**edge 是成本的 9.8 倍**。用户明确说过「无论是短期杠杆 还是其他什么用户都不在意，
可以短时高倍获利确实是好的」。**这个策略的杠杆问题从未被测过。**

## 1. 为什么这个问题的答案在几何上，而不在优化上

一个永续合约的**爆仓价只取决于杠杆和维持保证金率，与仓位大小无关**。
本策略的仓位是按风险定仓的（`risk_per_trade` × 到 4×ATR 止损的距离），
所以**仓位大小不会移动爆仓价**。这意味着：

```
做空，L 倍杠杆，维持保证金率 mmr：
    爆仓价 ≈ 入场价 × (1 + 1/L − mmr)
止损价   = 入场价 × (1 + stop_pct)        stop_pct = 4 × ATR%

止损能被执行  ⟺  stop_pct < 1/L − mmr  ⟺  L < 1 / (stop_pct + mmr)
```

**这是一个可以闭式求解的约束，而且它逐笔、逐币可算——不需要跑回测。**
它也是本项目里唯一一个「加杠杆」这个动作**真正**被什么东西限制的地方：
不是手续费，不是回测里的收益曲线，是**止损还能不能被执行到**。

## 2. 可证伪的方向性预测

* **H1（不利）：** 因为止损距离 = 4×ATR%，而高波动币的 ATR 可以到 7–10%，
  **至少有一部分持仓在 3–5 倍杠杆下，止损价在爆仓价之外——即永远等不到止损，先被强平。**
* **H2（有利）：** 若绝大多数持仓的 4×ATR 止损距离小于 8%，则 L_max > 10，
  杠杆在这一层上没有几何障碍。
* **H3：** 无论 H1/H2 哪个成立，**样本内表现最好的杠杆倍数不能当作估计**，
  因为 t 对仓位大小不变（见 §4）。

## 3. 门槛（在看到结果前写定）

| 编号 | 门槛 | 判据 |
|---|---|---|
| **L1** | 数据可用 | 每笔交易必须带 `open_rate` 与 `initial_stop_loss_abs`；缺字段即中止，**不得用默认值补** |
| **L2** | 几何正确性 | 手算一例（已知入场价、ATR、mmr、L）与脚本结果**逐位一致**；并对 L1.0、L2、L3、L5、L10 各断言爆仓价公式与交易所文档一致 |
| **L3** | **决定性门槛：多少比例的持仓止损可执行** | 在候选杠杆 L 下，**止损距离 ≥ 1/L − mmr 的持仓比例（即止损可执行）必须 ≥ 95%**。低于 95% 即该 L **不可用**，且**必须报告它不可用**——不得只报告可用的那一档 |
| **L4** | 跨币稳健 | 逐币看，**任何一个币的止损可执行比例 < 90% 即该币在该 L 下出局**（进整本账本的笔数 < 1% 也记为出局） |
| **L5** | 成本必须按权益口径报 | 报告每档的年化换手与**权益口径的费用率**（`fee × 杠杆 × 换手`），并与该档的毛收益对比 |
| **L6** | 级联情景 | 在实测的最差成本档（COVID 34.9 bps）下重算；若该档下权益费用率超过毛收益，该杠杆档**直接判不可用** |

**失败条件**：L3 在**所有**候选杠杆上都不通过 → **杠杆线关闭**，
照实报告「这个策略的止损架构与杠杆不相容」，不得改用更紧的止损重来（那是 STOP_MULTIPLE 线，已关闭）。

## 4. 停止规则与反 p-hack 约束

* **一次测量，发布整条 frontier，绝不只报最好的一档。**
* **明确写死：t 对仓位大小不变。** 杠杆不改变 `mean/sd`，因此
  **杠杆不可能把 t 从 0.7 提到 2**。它只放大收益**和**回撤，同比例。
  所以「样本内最好的杠杆」是一个**必然偏高**的数，本预注册**不允许**把它当作
  可部署的估计——只允许把 **L3 的几何上限**当作上限。
* 本轮**不修改**已交付的策略、配置或任何历史结果文件。
* 本轮**不下真实订单、不使用交易权限凭证、不动真实资金**；如需回测只跑 dry/backtest。

## 5. 为什么这不是已关闭线路的翻版

* STOP_MULTIPLE（止损倍数）**已关闭**，本预注册**不动它**——4.0×ATR 是冻结参数，
  L-1 只是问「冻结的止损距离能承受多少杠杆」。
* 2026-09-27 的杠杆结论**是在另一个策略上测的**（5m 毛收益≈0）。
  同一个问题在 edge 是成本 9.8 倍的策略上，答案在原理上就不同。
* 币种、周期、信号全部冻结；本轮不新增任何选币或择时自由度。
