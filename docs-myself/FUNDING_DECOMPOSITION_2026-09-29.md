## 1. 先说结论

"这个策略赚的是资金费的租金，不是信号的钱"——**这个说法是错的**。

资金费在账本里**确实存在**（Freqtrade 2026.8 会加载并计入，此前所有结果都已经包含它），
但它只占净利润的 **0.9%–2.2%**，统计上与零无法区分（t 在 −1.30 到 +0.90 之间，从未接近 2）。
**删掉资金费，净利润几乎不变。**

### G3（跨期/跨标的稳定）——混合
full/n50 有 3/4 年为正、74% 的标的为正（G3 PASS）；但 OOS 段 **2025 +151 / 2026 −382**，
full/n100 **3/4 年为负**。不稳定。

### G4（是否是 P&L 的影子）——PASS，但它回答的不是"值不值得"
`corr(R, funding_R) = −0.039`（P&L 几乎解释不了资金费）；
**亏损交易上照样收钱**（+0.00082R，n=609），盈利交易上收得一样多（+0.00060R，n=644）。
总资金费的 **100%** 是"同一时刻对所有持仓收取的全局时间因子"。
**所以资金费确实是一条独立的现金流——只是这条流太小，小到没有统计意义。**

### G5（量级敏感性）——FAIL
把资金费整体缩放 0.5×/1.0×/1.5×（因为 mark 价是 4h 重采样的近似量），G2 结论在每一档都不成立。
**方向稳，量级也不足以翻转结论。**

## 3. 顺带测出的一件更重要的事：成本根本不是瓶颈

预注册的 G2 失败之外，这个分解还给出了本项目迄今最干净的一个结构性事实（full/n50，
**已按正确风险单位重算**）：

```
每笔交易的毛价差收益 (gross)      +0.1264 R
交易所手续费                       0.0116 R   (毛值的  9%)
资金费                             0.0025 R   (毛值的  2%)
----------------------------------------------
净                                 +0.1173 R

**每笔交易只要做出 0.0141R 就能覆盖自己的成本；本信号做出 0.1264R——超出 9.0 倍。**
```

**这直接推翻了"成本太高所以做不出来"这个框架。**
成本只吃掉毛值的 10%。如果价格信号为零，这本书会亏掉毛值的约 10%——它**完全靠择时活着**。

那么为什么 t 统计上不了台面？因为**不是成本问题，是统计功效问题**：
每笔 0.037R 的均值，对上的是单笔 R 分布上远大得多的离散度（4×ATR 止损 ⇒ 大量小额
盈亏 + 偶发 −1R）。要在当前噪声水平上分辨 0.04R 的均值，需要的独立观测数比现有的多好几倍。

**这个数字改变下一步该做什么**：继续压成本（更紧的止损、选低波动标的、换更便宜的
下单方式）是错的——成本只有 10% 的量。**该做的是降低单笔噪声、提高有效样本量。**
（§「这推翻了什么」一节记录了它推翻的既有说法。）

## 5. 本轮自己踩的坑（记录，因为它们是可以复用的）

同一个脚本里，我写出了**两个结构上不可能通过的门槛**，两次都是"拟合了截距"。
这两个错误各自产出了一张看起来完全正常的表。

1. **v1 G4**：把 `funding_R` 对 `(1, R)` 做回归，再检验"残差均值 > 0"。
   拟合了截距 ⇒ 残差均值恒等于 0 ⇒ 门槛恒假。三个结果集都报 `t = -0.00`。
2. **v2 G4**（更花哨的版本）：按时间戳横截面去均值，再检验"残差均值 > 0"。
   去均值同样强制每个时间戳的均值为 0 ⇒ **同一个恒真式，换了个名字**。
   三个结果集仍然报 `t = +0.00`。

**教训：门槛必须是"数据能违反"的。** 写完之后倒过来问一句——
*什么样的数据会让这条判为 FAIL？* 如果答不上来，这条就不是门槛，是装饰。
第二次是我把"更复杂的去均值"当成"更正确的控制"，实际上复杂度掩盖了同一个错误。

另外两个小错：`cost_R` 的符号写反了（`-(fee_R + funding_R)` 得到负的"成本"）；
G5 打印净 P&L 时写成 `tot_p - u + u`，那个表达式恒等于 `tot_p`，看起来像在算东西。
三个 bug 都没有让脚本崩溃，都产出了正常表格——**又一次印证"不报错"不等于"算对了"**。
