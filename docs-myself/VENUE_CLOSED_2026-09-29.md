## 0. 改判：从 BLOCKED 到 CLOSED

上一轮我写的是 **BLOCKED**，理由是「必需 feed 不可得，但换 OKX 可能可行」。
**这一轮把 OKX 测了，答案是也不行**——而且不是「也不行但慢」，是**根本不存在**。

| | 资金费历史深度 | 能否翻页到 2023 |
|---|---|---|
| **Bybit** | **1–2 个月** | `end` 游标不推进；`startTime` 被拒（`10001 Time Is Invalid`） |
| **OKX** | **约 3 个月**（296 行，2026-06-22 → 2026-09-28） | `after` 游标在第 4 页返回**空**（`code=0`，不是错误） |
| **OKX 批量归档** | — | **6 个候选路径全部 404**，含官方 data-download 页 |

**所以：两个交易所的 REST 资金费都被封顶在 1–3 个月，且都没有批量归档。**

**BLOCKED 和 CLOSED 的区别是有意义的：**
- **BLOCKED** = 缺的是必需 feed，但**存在**一条能拿到它的路
- **CLOSED** = **再多下载也改变不了**

**上一轮我写「换 OKX 也可行但慢约 5 倍」——那句话是错的。**
我当时只测了 OKX 的**K 线**翻页（76 页，可行），**没有测它的资金费**，
而资金费才是阻塞项。**这正是下一节要说的事。**

## 1. 这一轮真正的收获：Gate 0 的顺序错了，而且修正它很便宜

上一轮的顺序是：

```
探测场所 → 下载 190 个币的 4h K 线（107 秒）→ 写导出器 → 发现资金费拿不到 → BLOCKED
```

**我先下了最容易拿的数据，然后才发现那个会阻塞的数据拿不到。**

这一轮改成：

```
先测会阻塞的 feed（单币，30 秒）→ 答案：OKX 也不行 → 结案
```

**省下约 90 分钟的下载和一堆导出代码。**

> **规则：Gate 0 要测的是那个「缺了就会 BLOCK」的数据源，
> 而不是那个「最容易拿到」的数据源。**
> **最容易拿的永远拿得到，所以先测它等于没测。**

---

## 2. 为什么这条线值得存在过

因为**近期所有结果都是成本故事**：

- 最流动的 50 个币：+89.9%（实测 COVID 成本）
- 全部 515 个：−33.1%
- 均值 R 随宇宙宽度单调下降（0.2954 → −0.4855）
- §1c 的 `cost_R = bps/(stop倍数 × atr_pct × 1e4)` 精确预测这个次序

**而这些全部是对 Binance 的测量。** 一个不同订单簿、不同费率、不同上市宇宙的场所，
是一个真实的、独立的、可能推翻或确认「成本故事」的工具。

**它没能被测，不是因为想法不好，是因为两家交易所都不提供 2023 年以来的资金费归档。**

---

## 3. 为什么不用「省略资金费」把它跑出来

**这是本轮唯一需要克制的诱惑，而且理由比上一轮更清楚了。**

资金费在这本账里不是装饰：4×ATR 止损约合价格的 9.5%，
7 天持仓约 21 次结算，按 1 bp/8h 算是 0.21% 的名义成本 = **约 0.022R**。
而这本账的净 R 是 **+0.12 ~ +0.21R**。

**所以资金费大约是效应的 10–18%。** 省略它不是「小修正」，
**它恰好落在能改变档位排序的量级上**——而整个假设就是关于成本的。

**用 Binance 的资金费配 Bybit/OKX 的价格是 proxy 替换**（charter §2.C 明确禁止），
而且资金费确实因场所而异：本仓库 §2 记录了 Binance 的资金费被其 clamp **设定**，
He et al. (2026, v7) 测到跨场所相关 0.74——**相关，但不相等**。

**所以：CLOSED。如实结案，不做近似。**

---

## 4. 一个仍然成立的观察：数据可得性和策略无关

**两家交易所都有 2023 年以来的完整 4h K 线**（Bybit 190 个符号 107 秒下载完），
**但都没有同期的资金费。**

**这意味着任何依赖资金费的跨所研究，在今天都是做不了的**——
不是 Binance 的问题，是整个行业的数据可得性问题。
**如果有人（包括我）未来声称做过跨交易所的永续研究，
第一个该被问的问题是：你的资金费从哪来的。**
