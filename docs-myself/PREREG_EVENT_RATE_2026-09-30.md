# 预注册 E-1：信号的事件率，而不是每笔 edge，才是瓶颈——先量事件率，不回测

日期：2026-09-30 · 状态：**在看到任何事件数之前冻结** · 类型：Gate 0（纯计数，零回测）

---

## 0. 为什么这是一个新问题，而不是已关闭线路的调参

本项目此前优化的一直是**每笔交易的 edge**，不是**事件发生的频率**。
理由是本轮刚测出来的（`RESEARCH_STATE.md` §15c）：

| 量 | 值 |
|---|---:|
| 每笔净 R | +0.1173 |
| 每笔标准差 | 1.022 |
| 达到 t=2 所需独立时间戳 | **1,159** |
| 实际拥有的独立时间戳 | **423** |
| 平均同时持仓数 | **3.0** |

**瓶颈不是每笔赚多少，是样本里根本没有那么多次独立的交易。**
成本只占毛值的 11%，横截面又几乎是一个因子（§15c-3）——
**所以唯一还能动的杠杆是「多发生几次」。**

`STOP_MULTIPLE` 和流动性阶梯都是在**每笔 edge** 这条线上关掉的，
**从没有人把「事件率」当成目标来测过**。
按 charter §2.A.4，这是一次有结构性理由的重开：**新理由（约束是 n_eff 而不是每笔 R）
是在关闭之后才被测出来的**，不是事后找的。

## 1. 机制与方向性预测

冻结的信号是**三个条件的合取**（`PerpShort4h.populate_indicators:231-235`）：

```
shark_short = (rvol >= 2.0) & (close < prev_low_20) & (vol42 < vol42_med_365)
                 相对量        20 bar Donchian 破位        低波动过滤
```

**合取会把事件率乘起来。** 方向性预测：

* **H1（有利）**：某一个条件单独放松就能把事件数放大 2 倍以上。
  那么 §15c 的 n_eff 问题是**可解的**，而这条线**不该被关**——
  正确做法是选放大率最高、且不牺牲每笔 edge 的那一个条件。
* **H2（不利）**：三个条件里任何单独放松都只带来 <1.5 倍的事件。
  那么**合取的代价是结构性的**，事件率上不去，**这条线确实到顶了**。

**可证伪性**：H2 由一个明确的数字定义（§3 的 G2），不存在「看起来有希望」这个出口。

## 2. 候选与测量口径

**在看到结果前固定 3 个条件各自的放松网格，外加原配置：**

| 条件 | 冻结值 | 放松网格 |
|---|---|---|
| `rvol_threshold` | **2.0** | 1.9, 1.8, 1.7, 1.6, 1.5, 1.4 |
| `breakout_period` | **20** | 16, 12, 10, 8 |
| 低波动过滤 | **开** | **关**（单个格子，用来量这一个条件的全部贡献） |

**测量的是「每根 4h bar、每个币、产生多少个信号」**，用仓库里已有的 4h 数据，
**不回测、不算 P&L、不动任何交付物**。

同时报告**每个候选的 3 个条件的通过率**（单独的与合取的），
这样能看出是哪一个条件在卡事件率。

## 3. 门槛（在看到任何计数之前写定）

| 编号 | 门槛 | 判据 |
|---|---|---|
| **E1** | 计数可复现 | 原配置的事件率必须与已发布结果一致：**部署版 1,111 笔 / 3.44 年 / 40 币**。若计数口径与引擎对不上，**先修口径，不得解读任何候选** |
| **E2** | **决定性：放大率** | 至少一个候选的事件放大率 **≥ 2.0×**。低于 2.0×，**这条线就此确认关闭**（理由写在 §5） |
| **E3** | 成本不得被破坏 | 候选若通过 E2，必须在**第 5 节的功效算术**上仍能到达 t=2；算不到就不算通过 |
| **E4** | 不在本轮回测 | 本轮**只数事件**。任何候选即使通过 E2+E3，也必须**另开预注册**才能跑回测 |

**失败条件**：E2 不通过 → **事件率不是杠杆，4h 这条线以「已测量」的方式正式关闭**，
并且要写清楚**关闭的理由是 n_eff 而不是成本**。

## 4. 严格约束

* **不回测、不动策略、不动配置、不改任何已发布结果。**
* **不按结果挑候选**：全部网格都会公布，E2 只判断「有没有」，不判断「哪个最好」。
* 如果 E2 通过，**下一步是另开预注册**，不是本轮顺手跑一个回测。
  理由：事件率是一个新目标，而按新目标选出来的参数是一个**新的选择自由度**，
  必须在看到 P&L 之前写死它的通过标准。

## 5. E3 的功效算术（提前写死）

n_eff 近似正比于**独立时间戳数**（不是 bar 数，因为 IAT ≈ 2.4）。
部署版：423 个时间戳、n_eff 175、t ≈ 0.58（full/n50 口径）。

```
需要的放大率  ≈ (2 / 0.58)^2 ≈ 11.9x
```

**⚠ 注意这个数字：要到 t=2，需要约 12 倍的独立时间戳，不是 2 倍。**
E2 的 2.0× 门槛因此**只是一个「值得继续看」的筛子，不是「够用」的证明**——
两者相差 6 倍，这件事必须写在结论里，否则「放大 2 倍」会被误读成「问题解决了」。

**E3 因此是一个几乎不可能通过的门槛，而这是对的**：
它诚实反映了 §15c 的结论——**这个瓶颈大到不是调参能解决的。**
