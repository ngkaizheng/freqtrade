## 0. 结论先行

**回答了用户的问题，但答案是分层的，不是简单的是或否。**

| 策略 | CAGR | **Sharpe** | 最大回撤（账户） |
|---|---:|---:|---:|
| **BuyAndHold（买入持有）** | **88.82%** | **1.22** | **84.85%** |
| VolTargetHold（波动率目标） | 45.86% | 1.13 | 70.14% |
| TrendVolTarget（SMA200+波动率目标） | 41.85% | 1.19 | 56.73% |
| DonchianVolTarget（唐奇安突破+波动率目标） | 34.20% | 1.20 | 56.39% |

**三句话：**

1. **牛市里确实有钱赚 —— 而且最好的策略就是"拿着不动"。** 买入持有 CAGR **88.82%**。
   **没有任何一个策略跑赢它。**
2. **熊市的伤害是真的可以减轻的。** 最大回撤从 **84.85% 降到 56.4–70.1%**，
   大约砍掉三分之一。这个机制（波动率目标）是复现了 E#8 的发现。
3. **但代价是牛市收益**：CAGR 从 88.82% 掉到 34–46%。
   **风险调整后（Sharpe），还是买入持有最高。**

## 1. 预注册门槛的裁决 —— 以及我的预注册写错了

预注册写的三条门槛：

| 门槛 | 结果 |
|---|---|
| 1. Sharpe ≥ 0.95 | **三个全部通过** |
| 2. 最大回撤优于买入持有 | **三个全部通过** |
| 3. CAGR 为正 | **三个全部通过** |

**但这里必须说清楚：我的预注册门槛设错了。**

我把 Sharpe 门槛设成 0.95，**而买入持有本身就是 1.22**。
所以三个策略通过的是一条**低于基准**的门槛 —— 它们"通过"了，却全都输给了基准。

按 `AGENTS.md` §5，这个错误我直接写在报告里，不掩盖：
**真正有经济意义的门槛应该是"跑赢买入持有的 1.22"，而三个都没有。**
（这条更严格的判据是在看到基准之后补的，但基准不是策略结果，且三个策略结果当时尚未看到。）

## 2. 而且这些差距远在噪声之内

- 窗口 13.7 年 ⇒ **SE(Sharpe) ≈ 1/√13.7 = 0.27**，**最小可检出 Sharpe = 0.54**（Lo 2002）
- 三个策略与买入持有的 Sharpe 差距是 **0.02–0.09**，是检测下限的 **1/6 到 1/27**

**所以正确的表述不是"买入持有赢了"，而是"这四个在统计上分不出来"。**
按 `AGENTS.md` §3，我不会从这 0.09 的差距里宣称任何发现。

## 3. 参考：BTC 为什麽基准这么高

买入持有逐年收益（同一份数据，2011 起）：

| 年 | 收益 | | 年 | 收益 |
|---|---:|---|---|---:|
| 2013 | **+5437.1%** | | 2020 | +303.9% |
| 2014 | −57.5% | | 2021 | +57.2% |
| 2015 | +37.3% | | **2022** | **−65.4%** |
| 2016 | +122.7% | | 2023 | +154.3% |
| 2017 | **+1291.1%** | | 2024 | +111.3% |
| **2018** | **−72.5%** | | 2025 | −7.3% |
| 2019 | +87.5% | | 2026 | −8.4% |

**牛市年份是天文数字，熊市年份是 −65% 到 −72%。** 这就是"牛市能赚、熊市很痛"的具体形状。
也说明了为什么任何降风险动作都会付出巨大机会成本：牛市涨幅太大，
少拿一点仓就少赚很多，而熊市一年只发生几次。

> **一个必须说明的限制：** 买入持有 13.7 年 Sharpe 1.22 是 **BTC 2013–2026 这段特定历史**
> （6,147 倍）的产物，不是一个可以外推的属性。把它当作"该策略的长期 Sharpe"是错的。

## 5. 已知陷阱（本轮踩到的）

- **各策略评估窗口不同会伪造出结论。** 第一次跑时 VolTargetHold 有 220 天 startup，
  实际从 2012-03 才开始（当时 BTC 约 $4.5），而我的基准从 2011-08（$10.90）算起。
  两者相差 2.4 倍。**必须用同一 timerange 跑，让 freqtrade 在窗口外消耗 startup。**
- **`Sharpe (closed trades)` 对这类策略是退化值**（VolTargetHold 只有 1 笔 → 显示 −100）。
  正确的指标是 **`Sharpe (daily wallet balance)`**。
- **不要拿 freqtrade 的 Sharpe 和手算的 Sharpe 比。** 年化因子可能不同（252 vs 365）。
  基准必须也走 freqtrade，所以写了 `BuyAndHold.py`。
- `order_types` 缺 `stoploss_on_exchange` 会导致策略加载失败；
  市价单要求配置里 `entry_pricing.price_side = "other"`。
- **`EXIT=0` 可能骗人** —— 第一轮 PowerShell 报了 EXIT=0，日志里却是 ERROR。必须查日志。
