## 2. 它**不是**什么

* **不是选币 alpha。** 市场中性化后的超额收益**为负**（N=25 处 −1.300%，t=−2.54）。
* **不是统计显著的。** 按时间戳聚合、依赖调整后 **t ≈ 0.58**。
* **不是能被 3.4 年数据证明的。** 见第 4 节。
* **不是「加杠杆变好」。** t 对仓位大小不变；几何上限 3 倍，且 3 倍没有意义。

## 4. 为什么「样本外确认」不可能——这是测出来的，不是推辞

* 每笔净 R **+0.1173**，成本只占毛值 **11%**——**成本不是瓶颈**。
* **77% 的单笔 R 方差是「共同因子」**；平均同时持仓只有 **3.0** 个。
* 这个宇宙在 **4h / 12h / 1d / 3d / 1w 的每一个周期上都是单一因子**：
  平均两两相关 **+0.48~+0.60**，第一主成分 **52–63%**，
  **50–99 个币只值约 3 个独立下注**。
* 五根可能的杠杆**逐一由测量关闭**：成本、宇宙宽度、周期、事件数量、事件质量。

**在「一个横截面 ≈ 一个因子」的周期上，一个 0.037R/笔的择时 edge，
在 3.4 年里是不可证明的。这不是实现缺陷，是市场结构。**

## 5. 一个诚实的负面结果，值得单独说

Q-1 发现**这个信号是分级的**：`rvol` 越高，之后 7 天跌得越多，
四箱严格单调、两端显著、**在两个独立窗口里各自复现**，
而最弱的一箱（968 个信号，占 45%）**做空是亏钱的**。

**这解释了 t 为什么上不去：账本把强弱信号一视同仁。**

但把它做成规则（只做 `rvol≥3.0`）之后：**组合 t 从 0.58 降到 0.36，收益从 +90.3% 降到 +29.0%。**
**一条更差的策略。已部署的规则保持不变。**

**两道沟解释了为什么：** 止损和目标把「7 天前瞻 −3.36%」截断成实际拿到的 −1R；
以及一因子结构让同时入场的几笔互相抵消（逐笔平均 R +0.1431，批次平均只有 +0.0350）。

## 6. 三次自己犯的错，和它们教会的事

**（1）`RESEARCH_STATE.md` 被清成 0 字节。** 2026-09-30，一次 shell 里的按行号原地编辑，
未被 git 跟踪，约 3,400 行历史丢失。修法不是「以后小心点」，
而是**把状态文件改成生成物**：`tools/state_index.py --build` = 手写源 + 自动生成的 111 份文档索引，
并由 `tools/perp_short/state_gate.py` 守门。**一个只能被弄丢的手写索引 → 一个可以重新生成的索引。**

**（2）`cost_frontier.py` 根本不是在重定价。** 它忽略引擎导出的每笔 `amount`，
自己用 `atr_stop=1.5` / `risk=0.01` 重算仓位，**给每笔交易的仓位是部署版的 5.3 倍**，
于是同样的 bps 成本它要扣 5.3 倍——**本项目此前所有「实测成本」下的收益都被低估**。
引擎自己打印的数字一直是对的。**修法是给重定价工具加一道它绕不过的闸门：
它在引擎自己的成本下必须复现引擎的总收益（差 ≤ 2 pp），否则不许报出任何成本档。**

**（3）紧跟着测量出现的机制解释，被下一轮否掉。**
我测出风险前沿非单调，同一段里写下「机制是 `max_open_trades=24`」。
**下一轮把上限提到 96，三档高风险一个数字都没变。**
后来又测出「余额限制并发」——**也不完整：在 0.5% 及以下生效，0.75% 以上不生效**。
真正的答案是**两个约束在不同档位轮流当主角**。

> **三件事的共同形状：它们都产出了看起来完全正常的表。
> 抓住它们的不是仔细阅读，是别的东西——一个不可能的数（−8229% 的最差 12 个月）、
> 一份独立实现的 0.00 pp 复现结果、以及下一轮的独立检验。**
