# PREREG — OI-1: 持仓量与价格/资金费率，是否含有这两个已交付账都没有的信息

**写于 2026-09-30，在下载完成之前、在看到任何 OI 数值之前。**

---

## 1. 为什么是这个方向（不是「又一个策略」）

`docs-myself/GAP_ANALYSIS_2026-09-30.md` 把它排第一的理由是**结构性的，不是新鲜感**：

> **现有两本账都是纯价量趋势族，跑在同一个 40 币宇宙上。**
> 第三本如果还是价量趋势，**必然**和前两本高度相关——那不是分散，是同一个赌注下两次。

**OI 是唯一一个能回答「这次价格变动背后有没有新仓位」的量。** 价格和成交量给不出这个。
所以 OI-1 的目标**不是**「再做一个赚钱的策略」，而是先回答一个更前置的问题。

## 2. 先验（写下来，之后不能改）

| 命题 | 我的预期 | 为什么 |
|---|---|---|
| OI 变化率对未来收益有增量预测力 | **弱，可能为零** | §15c 已测：横截面在所有周期都是单一因子，OI 大概率也是同一因子的另一个读数 |
| OI 与价格的**交互**（不是 OI 本身）有信息 | **比 OI 本身强** | 价涨+OI涨=新多头；价跌+OI涨=新空头。**这是 OI 独有的正交维度** |
| `count_long_short_ratio`（散户多空比）有反向预测力 | **中等** | 散户拥挤是经典反向指标 |
| `sum_taker_long_short_vol_ratio` 有短期预测力 | **中等** | 主动买卖失衡 |

**如果结果和这些预期一致，本轮就是一个阴性结果，但它是「实测过的阴性」而不是「没看」。**

## 3. 预注册的判决规则（**在看到数据之前写死**）

### Gate 1 — 数据可用性
40 个部署币 × 2023-01-01 → 2026-08-31（1,339 天），
**至少 30 个币有完整覆盖**。不足 → 记 `INSUFFICIENT_DATA`，**不发布任何 OI 数字**，转 Tier 2。

### Gate 2 — OI 有没有信息（在 4h 上，**不含交易**）
对每个币、用 4h bar：
- 特征：`ΔOI%`（1/4/12 根 bar）、`OI 变化 × 收益符号`（交互项）、
  `count_long_short_ratio` 的 z-score、`sum_taker_long_short_vol_ratio`。
- 标签：未来 4h / 12h / 24h 的**对数收益**。
- 检验：Spearman IC + Newey-West t（4h 收益自相关，必须调整，否则 t 是假的）。

> **通过线：至少一个特征在 12h 上 |IC| ≥ 0.02 且 NW-t ≥ 2.5。**
> **失败线：全部特征 |IC| < 0.02 → OI 作为独立信息源判死，本方向 CLOSED，转 Tier 2。**

### Gate 3 — 对照组（**这一条是本轮最重要的设计**）
同一个检验跑在**成交量变化率**和**纯粹的价格动量**上，作为「特征里到底有没有 OI 特有信息」的对照。
> **只有当 OI 特征的 IC 显著优于对照组，才算 OI 贡献了新信息。**
> **OI 有效但和成交量一样有效 = 没有新信息 = 不构成第三本账的理由。**

### Gate 4 — 与现有两本账的相关性
若 Gate 2、3 都通过，才构造候选策略，并用**日收益**算它与空头账（`PerpShort4hDeploy`）、
多头账（`PerpLong4h.py`）的相关性。
> **通过线：与两者的日相关 < 0.3。** §50 已实测两本之间是 +0.007，所以这是可达的。

## 附录 A（2026-09-30，判决之前写入）：**Gate 2 检验本身的功效，以及它能证明什么、不能证明什么**

**本附录不修改上面任何一条通过线。** 它记录的是**通过线所依附的那个检验的能力边界**，
写在判决之前，因为 `AGENTS.md` 1a 要求先算清楚实验能不能得出结论——**而这一条适用于闸门本身**，
不只是策略。

### A.1 自测抓到的两个错误（若没做自测，会得到一个「OI 没有信息」的错误结论）

| 版本 | 错误 | 会打印出什么 |
|---|---|---|
| v1 | `x = x - x.mean()` 之后又返回 `x.mean()/se` —— **减完均值的均值是 0** | **所有 t = 0.00 → Gate 2 全部 FAIL → 打印「OI 没有信息」** |
| v2 | 用两条**原始秩序列的乘积**当检验统计量。零假设下 `E[rank_x·rank_y] ≈ ((n+1)/2)² ≈ 1.6e7` | 纯噪声上 **t = +101，100% 触发** |

修正后自测（`tools/perp_short/check_ic_t.py`，固定种子 20260930，300 次重复）：
**NULL 触发 4.3%（应约 5%）· NW t / 朴素 t = 0.411 · NW 把触发率从 49% 压到 10.7 %** —— 全过。

> **一个 bug 伪装成一个阴性结论，还顺带关掉一整条研究方向。**
> 这是本项目同一形状错误的一次重复，**也是唯一一次在它能造成结论伤害之前被抓住的**。

### A.2 功效曲线（在**实测**自相关下测得）

**实测：本面板 4h 收益的 lag-1 自相关 = −0.003（区间 −0.026 ~ +0.018），基本为零。**
自测第一版用 AR(0.90) 合成数据把 n_eff 压到 ~423，测出的是**错的**功效。

| 真实 IC | 在 t ≥ 2.5 门槛上的检出率 |
|---:|---:|
| 0.010 | 2.0 % |
| 0.015 | 9.0 % |
| **0.020**（预注册通过线） | **10.5 %** |
| 0.025 | 27.0 % |
| 0.030 | 38.0 % |
| 0.040 | 77.0 % |
| 0.050 | 91.0 % |
| 0.080 | 100 % |

### A.3 所以，Gate 2 的判决只能这样读

- **通过 → 结论成立。** 零假设下该门槛触发率约 5 %，所以「通过」是真信号。
- **不通过 → 不能推断「OI 没有信息」。** 只能推断：
  **「OI 的效应量没有大到让一个在 IC=0.02 处只有约 10 % 功效的检验检出。」**

> **因此本方向的成功条件是 Gate 2 **通过**，而不是「Gate 2 不通过且 Gate 3 也不通过」。**
> **Gate 2 不通过时，本轮结论只能是 INCONCLUSIVE（功效不足），不是 CLOSED。**
> 除非实测 |IC| ≥ 0.08——那时不通过才是有说服力的阴性。

**写这一节是为了让「不通过」这个结果无法被事后解释成任何我想要的说法。**
