# 预注册 F-1：资金费率（funding）在已交付账本中的分解

日期：2026-09-29 · 状态：**在看结果之前冻结** · 类型：账本分解（post-hoc decomposition），不是新策略搜索

---

## 0. 一句话

把已交付的 4h 做空账本拆成**毛收益 / 手续费 / 资金费**三块，问：赚到的钱里，有多少来自**持仓结构本身**（短头寸收租），有多少来自**信号**（择时）。

## 1. 为什么现在做这件事

* 当前交付物被反复描述为"择时工具，不是选币 alpha"，且市场中性化后的超额收益为负
  （`VERDICT_4H_SHORT_2026-09-28.md`：每个通过 t≥2 的档位超额都为负）。
* 但 P&L 里还有一整块从未被单独报告过的量：**永续合约资金费**。Freqtrade 2026.8 在回测里
  **确实**会加载并计入 funding（`freqtrade/optimize/backtesting.py:416-465` 载入 funding+mark，
  `_run_funding_fees` 在资金费时间戳上累加；`exchange.calculate_funding_fees` 的符号是
  **空头收正 funding 为正收益**）。它一直在结果里，只是从来没有被拆出来看过。
* 如果这块占比很大，那么"这个策略为什么赚钱"的答案和现在写在文档里的答案不是同一个。
  这直接决定交付物该怎么描述、值不值得继续投入。

**这是记账，不是新假设。** 不产生新的策略选择，因此不构成 p-hack；但因为会看到一个新的
big number，必须在看到前把门槛写死。

## 2. 观察泄漏声明（重要）

在写这份预注册之前，为确认"funding 到底有没有被计入"而打开了一个结果包，**只看到了一个数**：

> n50 全区间，1,253 笔交易，funding_fees 合计 **+3,132.00 USDT**（1,248 笔非零）。

这是数据核查的副产品，不是预测目标。记录在此以免它日后被伪装成"事先预测到的结果"。
**下面所有门槛都是在这个数出现之后才写的**，因此它们不能被当作对该数的独立验证；
能作的独立验证只有：符号、按年稳定性、按标的稳定性、部分回归后的残差。

## 3. 机制与方向性预测

* 空头在 funding > 0 时**收取**资金费（`exchange.py:4008`：short 时原样返回，
  long 时取负）。
* 加密永续的 funding 在多数时间里为正（多头拥挤、合约贵于现货）。
* **方向性预测**：本策略净空头，因此 funding 应为**正的贡献**，且
  **与交易盈亏符号无关**——亏损的仓位也可能在收租。

**可证伪性**：若 funding 合计为负，或为正但只在少数暴涨/暴跌时段出现，则假设被否。

## 4. 单位与恒等式

每笔交易：

```
R        = profit_abs / (stake_amount * |initial_stop_loss_ratio|)
funding_R = funding_fees / (stake_amount * |initial_stop_loss_ratio|)
fee_R     = (fee_open + fee_close) * stake_amount / (stake_amount * |initial_stop_loss_ratio|)
gross_R   = R + fee_R - funding_R          # 恒等式：profit = gross - fees + funding
```

`initial_stop_loss_ratio` 存在于结果 JSON（已核对一条：0.3，与 4×ATR 一致）。

**G1（记账恒等式）**：`gross_R` 必须在符号与量级上等于"不扣费不计 funding 的纯价差收益"，
残差 < 0.01 USDT/笔。若不闭合，说明字段含义与假设不同，**分析作废，不得解读**。

## 5. 门槛（结果揭晓前写定）

| 编号 | 门槛 | 判据 |
|---|---|---|
| **G1** | 记账自洽 | 恒等式残差 < 0.01 USDT/笔；非零 funding 覆盖 ≥ 95% 的交易 |
| **G2** | 资金流是**独立的正收益流** | `mean(funding_R) > 0` **且** 依赖调整后的 t ≥ 2（按时间戳聚合，同 `r_stats.py` 口径） |
| **G3** | 跨期稳健 | 按自然年拆分，funding 为正的年份 ≥ 3/4；按标的拆分，funding 为正且样本 ≥30 笔的标的占比 ≥ 60% |
| **G4** | 不只是市场 β 的残影 | 对每笔交易的 `R` 做部分回归，`funding_R` 残差均值 > 0，t ≥ 1 |
| **G5** | 量级诚实 | mark 价是 **4h 重采样**的近似（见 `WIDENED_UNIVERSE_RESULT`），故给出 funding ×0.5 / ×1.0 / ×1.5 三档；若结论在 ×0.5 档就翻转，则只能报"方向成立、量级不可信" |

**失败条件**：G2 不成立 → **关闭资金费线**，照实报告测量值，不得改口径重算。
G1 不成立 → 整份分析作废。

## 6. 停止规则

* 一轮测量，**一次**。不按 N、不按年份、不按标的选择 funding 最优子集再报。
* 本轮不新建 funding 策略。若 G2 通过，资金费作为**独立机制**另立预注册
  （纯 carry，无择时信号），并按 §1a 先做功效计算——那需要的数据此处已有。
* 不修改任何已交付的账本、配置或策略文件。

## 7. 判定后要改什么

并修正 `HOW_TO_RUN_2026-09-29.md` 里对收益来源的描述——如果现在的描述是错的。
