# 1. 我的真正目标

我不是在寻找：

- 永久持有 5–10 年的项目
- 单纯 protocol revenue 很高的项目
- 单纯 market cap 很低的项目
- 单纯叙事很热门的项目
- KOL 推荐的“潜力百倍币”

我的目标是：

> **寻找“Catalyst Repricing Trade”机会。**

也就是：

```text
当前市场价格 / 市值
        ↓
市场尚未完全定价的事件
        ↓
事件兑现
        ↓
新的真实数据出现
        ↓
市场重新估值
        ↓
价格快速 re-rating
        ↓
我在 re-rating 过程中分批退出套利
```

我不是要永久持币吃现金流。

**我的核心目标是：在 catalyst 被市场充分定价之前建立仓位，在市场重新定价过程中退出。**

# 7. 第一原则：项目成功 ≠ Token 成功

永远区分：

```text
Protocol success
        ≠
Token value capture
```

例如：

一个项目：

- Revenue 很高
- User 很多
- TVL 很高

但如果：

- holder revenue = 0
- 没有 buyback
- 没有 burn
- 没有 staking cash flow
- token 只是 governance

那么：

> **不能因为项目成功就自动认为 token 有 upside。**

CARDS / MORPHO 类型项目就是这种典型例子。

# 8. Evidence Hierarchy

每个结论都必须尽量区分证据等级。

### Level 1 — On-chain verifiable

最高级：

- burn tx
- buyback wallet
- token transfers
- actual fees
- actual revenue flows
- contract activity
- treasury movements
- supply change

### Level 1.5 — On-chain event confirmed, attribution uncertain

例如：

链上确实看到一个 wallet 买回 token，

但无法确认：

> 买回资金是否全部来自 protocol revenue。

这种不能直接当作“协议收入”。

### Level 2 — Protocol accounting / dashboard

例如：

DefiLlama methodology、protocol dashboard、official financial data。

### Level 3 — Official project claims

项目方说：

- revenue
- users
- partnerships
- roadmap
- future buyback

这些可以使用，但不能默认等于已验证事实。

### Level 4 — Secondary / narrative

例如：

- KOL
- Twitter
- Reddit
- Crypto media
- research reports

只能作为线索或市场 sentiment。

# 12. 计算 Catalyst Impact

每一个主要 candidate 都必须进行 scenario analysis。

例如：

### Current MC = $50M

计算：

```text
2× = $100M
5× = $250M
10× = $500M
20× = $1B
```

然后反推：

> **如果市场给这个 token 5×，协议需要达到什么经济规模？**

例如：

```text
Annual Holder Cash Flow
×
Reasonable Valuation Multiple
=
Target MC
```

或者：

```text
Current MC
vs
Annualized Holder Revenue
```

然后计算：

### Required Growth

例如：

```text
Current Holder Revenue = $2M
Target MC = $250M

如果合理 yield = 5%

Required Holder Revenue =
$250M × 5%
=
$12.5M
```

那么：

```text
$12.5M / $2M
=
6.25×
```

这告诉我们：

> **这个项目需要 revenue 增长 6.25× 才能在同样估值水平下支持 5× MC。**

这是非常重要的。

# 13. Catalyst Surprise

这是我最看重的变量之一。

我不是只想知道：

> “事件会不会发生。”

我要知道：

> **市场预期是什么？实际结果可能是什么？**

例如：

```text
Market expectation:
$500K burn

Actual:
$5M burn
```

则：

```text
Actual > Expected
```

→ Positive surprise

反过来：

```text
Expected:
$5M

Actual:
$500K
```

→ Negative surprise / sell-the-news risk

所以每个事件尽量寻找：

### Expected

### Base Case

### Bull Case

### Bear Case
